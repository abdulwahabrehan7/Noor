# Noor — Islam and Quran Website

A clean, straightforward web platform dedicated to Islamic resources and Quranic content.

**Live Demo:** [abdulwahabrehan7.github.io/Noor/](https://abdulwahabrehan7.github.io/Noor/)

## Overview
- Provides a simple, distraction-free interface for exploring Islamic content and Quranic resources.
- Designed with responsive layouts for easy access across all screen sizes.

## Tech Stack
- HTML5, CSS3, JavaScript
